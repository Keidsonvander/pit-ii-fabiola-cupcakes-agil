# PIT II — Cupcakes Gourmet | Fabiola Saviato

Projeto acadêmico de **Fabiola Saviato — RGM 33636702**, desenvolvido como continuidade da PIT I.

## Contexto
A PIT I trabalhou o desenvolvimento de uma solução para uma loja de cupcakes gourmet, com foco em vendas online, pedidos, pagamento, entrega e organização do fluxo de compra.

## Base utilizada
Foram considerados:
- requisitos funcionais e não funcionais;
- histórias de usuário;
- backlog priorizado;
- regras de negócio;
- critérios de aceitação;
- experiência do usuário;
- prototipação e organização das funcionalidades.

## Objetivo
Dar continuidade ao planejamento da PIT I e transformar os requisitos definidos em uma solução funcional e testável.

## PIT II
Nesta etapa foi desenvolvida uma aplicação web responsiva representando o fluxo principal de compra de cupcakes, incluindo catálogo, carrinho, dados do cliente, pagamento, entrega, confirmação e acompanhamento simplificado do pedido.
